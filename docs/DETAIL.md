# dsh-learn 私教

1v1 AI 私教：**先摸底，再定制；苏格拉底式追问；掌握了才能往下走；跨课程画像；间隔复习防遗忘。**

## 使用

对 agent 说"我想学 <主题>"，私教会：

1. 查询到期复习项（SM-2）并读取你的学习者画像；
2. 用 3–5 个开放问题摸底（不考背诵；提供材料时先读材料再出题），生成个性化路线图，跳过已会内容；
3. 每次只讲一个最小概念单元，讲完就追问；答错不直接纠正，顺着你的逻辑推矛盾；
4. 每个节点四维掌握度评分（准确性/理解深度/举一反三/辨别能力），≥80 才解锁下一节点；
5. 节点掌握后生成含你本人表述的笔记，并按记忆曲线安排复习；到期时主动提醒你回来复习。

## 面板与卡片

- **左侧边栏「学习分析」**：掌握进度折线图（每个计划一条线）、路线图结构图（DAG）、学习热力图、教学质量指标（追问密度、复习通过率）、多学习者筛选与数据导出。
- **会话内教学卡片**：评分四维条形图、路线图节点状态、判分错因、到期复习——替代原始 JSON。
- **插件详情页画像卡**：查看/编辑学习者画像（背景、强项、讲解与节奏偏好）。

## 数据主权

学习数据按学习者（`learn-<learnerId>/`）沉淀在当前工作区的 `dsh-learn/` 文件夹（JSON/Markdown，可直接查看）。画像可通过工具、插件详情页卡片查看/编辑；`ai_learn_export` / `ai_learn_import` 支持备份与迁移，面板也可一键导出。

## 限制

- 教学内容质量依赖当前模型；评分与追问由 `dsh-learn` 技能协议约束。
- v1 立场不变：不做一键总结、思维导图导出等"信息效率"功能；白板/语音留待后续评估。
